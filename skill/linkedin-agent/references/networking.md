# Networking

## Connection request notes
- Up to 300 characters; free accounts may have a lower monthly limit on notes.
- Formula: a specific reference (their post, talk or company news), plus why you're connecting, plus no ask.
- Give 2 variants.

## DMs / InMail
Write the first message plus a follow-up for day 4-5. Keep it to 3-6 sentences with one clear ask.

| Purpose | Shape |
|---|---|
| Cold outreach | Specific observation → relevance → low-friction question |
| Follow-up | Reference the last touchpoint → new value (resource or insight) → ask |
| Referral request | Context → the exact role/link → an easy out ("totally fine if not") |
| Collaboration | What you admire → idea → what's in it for them → next step |

## Recommendations
- **Give**: 120-180 words covering the relationship and context, one concrete story with the result, their standout trait, and an endorsement line.
- **Ask**: a short request plus 3 bullet points they could mention. Make it easy to say yes.

## Mini-CRM
Log contacts with a next follow-up date in the portal's Network tab. Review it weekly.

## Not possible via API
Sending DMs or connection requests. Always hand the user the text to send.
