# Engagement

## Commenting on others' posts
Write three variants:
- **A, insight**: add a point the author didn't make.
- **B, experience**: a short, specific story from the user.
- **C, question**: a sharp follow-up question.

Rules:
- 2-4 sentences.
- Don't open with "Great post!", don't pitch, don't add links.
- Use the author's name only if it reads naturally.

Suggest a reaction: Insightful for data, Celebrate for wins, Support for vulnerable posts, Love for stories, Funny for humor.

The best window is the first 60 minutes after the author publishes.

## Replying to comments on the user's post
- Reply to every substantive comment, ideally within the first 1-2 hours.
- Extend the thread: add value or ask a follow-up so the commenter replies again.
- Low-value comments (an emoji, "Great post") get a short thanks or a reaction.
- Never get defensive. Acknowledge, then add nuance.
- Threads on LinkedIn are only 2 levels deep, so reply to the top-level comment.

## Publishing
The MCP server publishes top-level comments (first comment) only. For replies inside threads, give the text to paste unless a reply tool is available.
