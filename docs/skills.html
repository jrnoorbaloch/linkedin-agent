All skills

39 skills. Each one is in the app (Create), over MCP (run_skill), in the CLI (linkedin-agent run <id>) and in the Claude skill.

article_writer		Long-form LinkedIn article or newsletter edition (here Markdown headings are allowed).
Trend Ideas

Add your own

Append a Skill(...) to SKILLS in linkedin_agent/skills.py. The app form, the API and the MCP tool pick it up automatically.
