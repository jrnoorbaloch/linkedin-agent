Claude skill, subagent & MCP

Three ways for an AI assistant to use the agent. Combine them for the best result.

1. The Claude skill

skill/linkedin-agent/ is a single skill that bundles every playbook (hooks, post writing, humanizer, profile, career, engagement, networking, company page, analytics, publishing) and routes each request to the right one. It works on its own: Claude writes everything. With the MCP server connected, it can also queue and publish.

skill/linkedin-agent/
├── SKILL.md              # routing, ground rules, workflows
├── references/           # 13 playbooks, loaded only when needed
└── scripts/la.py         # stdlib REST client for the portal

Install

  • Claude apps (claude.ai / desktop): download linkedin-agent-skill.zip, then go to Settings → Capabilities → Skills → Upload skill.
  • Claude Code: cp -r skill/linkedin-agent ~/.claude/skills/ (personal) or .claude/skills/ (project).

2. The subagent (Claude Code)

agents/linkedin-agent.md defines a LinkedIn manager subagent with routines for the daily post, weekly plan, profile and career overhaul, and weekly review.

cp agents/linkedin-agent.md ~/.claude/agents/
# then: "Use the linkedin-agent subagent to plan and draft my week"

3. The MCP server

Any MCP client can drive the agent: Claude Desktop, Claude Code, Cursor, Windsurf, or your own agent.

Claude Desktop / Cursor (mcpServers config)

{
  "mcpServers": {
    "linkedin-agent": { "command": "linkedin-agent", "args": ["mcp"] }
  }
}

Claude Code

claude mcp add linkedin-agent -- linkedin-agent mcp

Remote / HTTP

linkedin-agent mcp --http      # streamable HTTP transport
The MCP server and the portal share the same database (LA_DATA_DIR). Connect LinkedIn once in the portal and both can use it.

Tools

ToolPurpose
statusLinkedIn connection, LLM, brand profile, post counts
list_skillsAll skills with their input fields
run_skillRun a skill with the agent's own LLM (drafts are saved)
get_skill_promptGet the skill's prompt so the calling model writes the content itself
save_draftPut a post you wrote into the approval queue
list_postsList posts by status
approve_postApprove or schedule a draft, only after the user says yes
publish_postPublish an approved post and return its URL
record_metricsStore impressions, reactions, comments and reposts
get_brand_profile / update_brand_profileRead or update voice, audience and pillars
add_storyAdd to the Story Bank
list_documents / save_documentResumes, cover letters, plans

Approval gate

publish_post refuses any post that hasn't been approved. The skill and the subagent both instruct the model to call approve_post only after you explicitly say yes to the exact text.
