FAQ

Is this allowed by LinkedIn?

It only uses LinkedIn's official, documented APIs with your own developer app and OAuth consent: posting as yourself (and as a Page once approved). It does not scrape, automate a browser, or send messages or connection requests. As always, follow LinkedIn's User Agreement and API terms.

Why can't it update my profile automatically?

LinkedIn offers no public API for editing profile sections. The Profile Optimizer writes the headline, About, experience bullets and more so you can paste them in.

Which LLMs work?

Anything OpenAI-compatible (OpenAI, Gemini, Groq, OpenRouter, DeepSeek, Mistral, Together, LM Studio, Ollama) plus Anthropic Claude natively. From Claude or another MCP client, the calling model can also write content itself via get_skill_prompt + save_draft.

Will it post without me?

Only posts you approved. Drafts are never published, and the API refuses to publish an unapproved post. Auto-publish is off by default.

Where is my data?

In a SQLite file in LA_DATA_DIR on your machine. LLM keys and LinkedIn tokens are encrypted with a local key. Nothing goes anywhere except your LLM provider and LinkedIn.

Can I post to my Company Page?

Yes, after LinkedIn approves the Community Management API for your app and you're a Page admin. Set LINKEDIN_ORG_ENABLED=1.

Can I see analytics?

LinkedIn restricts post analytics for self-serve apps. Enter the numbers in History (or via the record_metrics tool) and the weekly report will analyze them.

Can I host it for my team or clients?

Yes. Deploy the Docker image behind HTTPS, set LA_BASE_URL and LA_API_TOKEN, and add the public callback URL to your LinkedIn app. The current version is single-user, so run one instance per person.
