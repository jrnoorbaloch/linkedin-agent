Getting started

About 5 minutes: install, create a LinkedIn app, connect an LLM, fill your brand profile, approve your first post.

1. Install

Option A — pip (Python 3.10+)

pip install git+https://github.com/jrnoorbaloch/linkedin-agent
cp .env.example .env     # or create .env, see step 2
linkedin-agent serve     # → http://localhost:8787

Option B — Docker

git clone https://github.com/jrnoorbaloch/linkedin-agent.git
cd linkedin-agent
cp .env.example .env
docker compose up -d     # → http://localhost:8787 (data in ./data)

2. Create a LinkedIn developer app

  1. Go to linkedin.com/developers/apps → Create app. It must be linked to a LinkedIn Page (any page you admin; a placeholder page is fine).
  2. Products tab → add Sign In with LinkedIn using OpenID Connect and Share on LinkedIn. Both are self-serve, with no review.
  3. Auth tab → add the redirect URL http://localhost:8787/auth/linkedin/callback (or LA_BASE_URL + /auth/linkedin/callback if hosted).
  4. Copy the Client ID and Client Secret into .env:
LINKEDIN_CLIENT_ID=your-client-id
LINKEDIN_CLIENT_SECRET=your-client-secret

Restart, open Settings → Connect LinkedIn, and approve. Access tokens last about 60 days; the dashboard shows how many days remain.

Company Pages: request the Community Management API product for your app. After LinkedIn approves it, set LINKEDIN_ORG_ENABLED=1, reconnect, and use Settings → Load my pages.

3. Connect any LLM

In Settings → Language model, pick a provider, paste your key, and click Test connection. Keys are encrypted on disk.

4. Fill your brand profile

Every skill writes from it: role, audience, offer, 3-5 content pillars, tone, language, two or three past posts and your profile text. Add a few real experiences to the Story Bank, or use Create → Story Interviewer.

5. Draft, approve, publish

  1. Dashboard → Draft today's post now (or Create → Post Writer).
  2. Review it in the Approval queue: edit, then Approve, or pick a time and Schedule.
  3. Publish now posts it and adds your first comment. The live link opens.

6. Turn on the daily routine

Settings → Daily schedule: set the draft time and your timezone (e.g. Asia/Karachi). Optionally enable auto-publish, which posts the oldest approved post each day at your publish time. Drafts are never auto-published.
